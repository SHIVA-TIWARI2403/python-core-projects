## 📂 Included Mini Projects

| Project | File | Description |
| :--- | :--- | :--- |
| **🧮 Terminal Calculator** | [`calculator.py`](calculator.py) | Full-featured console arithmetic calculator supporting addition, subtraction, multiplication, division, and exponents. |
| **📅 Monthly Calendar Viewer** | [`calendar_app.py`](calendar_app.py) | Dynamic calendar generator using Python's standard `calendar` library. |

| **🎮 Tic-Tac-Toe Game** | [`tic_tac_toe_cli.py`](tic_tac_toe_cli.py) | Interactive two-player terminal Tic-Tac-Toe game with winning logic and board rendering. |

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/SHIVA-TIWARI2403/python-core-projects.git
   cd python-core-projects
   ```

2. Run any project directly with Python:
   ```bash
   python calculator.py
   python tic_tac_toe_cli.py
   python turtle_heart_animation.py
   ```
